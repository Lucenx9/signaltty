# UI and artwork contract
Leading static brand: decorative symbolic image then app-name label; trailing New Workspace button. Logical margins mirror with RTL. Branding never accepts keyboard focus or handles clicks. Native label preserves full app-name tooltip when ellipsized. Image uses Presentation accessibility role.

Regular app icon stays dev.signaltty.gui.svg; symbolic stays dev.signaltty.gui-symbolic.svg. Both remain GResource assets and installed under hicolor/scalable/apps. Color appears only in regular artwork; symbolic shapes are filled and recolored by GTK. Application ID, desktop entry, actions and terminal identity remain unchanged.
