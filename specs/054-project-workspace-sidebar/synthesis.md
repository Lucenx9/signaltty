# Architecture synthesis

Selected canonical server metadata (A) over client joins of worktree IPC (B).
Parent and independent Gemini scores agreed: A 23/25, B 13/25. Canonical identity
belongs with existing Git metadata; the client stores scope without owning Git
probe timing. Retained B's searchable native menu, path disambiguation and scoped
creation default. Rejected its filtered-row update and RPC failure latch. Corrected
A's visibility rule: an included child with an excluded parent must become a root.

A directory key avoids changing identity when a folder becomes a Git repository.
Metadata stays cached until refresh, with a finite background upgrade for legacy
snapshots. Bare primary directories remain valid identities; the creation form
stays editable. Projects are derived from open workspaces rather than independently
registered empty containers. Original sketches and judgment are transient files
under /tmp/project-sidebar-design; this document retains the resulting decisions.
