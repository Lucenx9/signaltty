# UI contract
Name and textual status occupy the primary row when space allows; native natural-size wrapping moves the state below identity at narrow widths or enlarged text. Compact root metadata retains location and child disclosure; children retain indentation. Selected or attention-bearing rows expose useful messages; task chips always remain visible. Selecting or restoring a row synchronizes both the old and new row immediately. User actions, row identity, terminal identity and project scoping remain unchanged.
Header shows branch/Detached HEAD, else agent names, else directory basename. Full identity/location is available through the named details button and tooltip; opening it exposes the existing full-path row and copy action. Narrow toolbar behavior and native focus remain intact; secondary header context is hidden in the overlay layout so the title has more room.
